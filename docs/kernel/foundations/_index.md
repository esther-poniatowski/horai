# Foundations

States what the method is about and what it presupposes.

## The problem

- [Overview of the kernel](overview.md): orients a reader in the method before any other note, and gives the order in which to read its notes
- [Class of problems](problem-class.md): states the conditions under which a situation is an instance of the problem, and the modulators that vary across instances
- [Diagnosis of a task inventory](diagnosis.md): explains why a centralized list of tasks neither selects work nor allocates attention

## The structure of the solution

- [Control questions](control-questions.md): states the nine questions that any solution must answer, and the mechanism that answers each
- [Dimensions](dimensions.md): states the dimensions along which the problem and its solution are structured, with the values that each admits
- [Layers](layers.md): separates the kernel from the profiles and from the modules by a test
- [Parameters](parameters.md): lists every numerical constant of the kernel, with its default and the way it is revised
- [Core and options](core-and-options.md): separates the minimal core of the method from the options that a profile turns on, and bounds the overhead of each

## The grounds

- [Commitments of the method](commitments.md): states the commitments from which the rules of the method follow
- [Status of the evidence](evidence-status.md): rates the support of each mechanism, and separates a tested claim from a default parameter
