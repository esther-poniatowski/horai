# Kernel

States the general theory on which `horai` rests: the class of problems that it addresses, the objects that a plan states, and the processes that govern them. No note of this folder uses the vocabulary of a domain.

> [!IMPORTANT] Where to start
> A reader starts with the [overview of the kernel](foundations/overview.md), which states the question that the method answers and the reading path through its notes.

> [!WARNING] Kernel, profile and procedure
> A note of this folder states a concept, a rule or the grounds of a choice. The values of a domain are declared in a [profile](../profiles/_index.md), the steps that apply a rule in the [procedures](../procedures/_index.md), and the fields of the records in the [specification](../specification/_index.md).

- [Foundations](foundations/_index.md): states the class of problems, the control questions, the dimensions, the commitments and the strength of support of each mechanism
- [Objects](objects/_index.md): defines the objects that a plan states, from the stream to the horizon
- [Processes](processes/_index.md): defines the rules that allocate attention, order work, control uncertainty and coordinate with external parties
