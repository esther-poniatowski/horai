# Modules

States the processes that serve one [role](../kernel/objects/stream.md#^roles) of work in particular domains. A module fills the sessions of a stream with a method, and the kernel gives that stream its capacity.

> [!IMPORTANT] Form of a module
> Each module names the role that it serves, the regime that it presupposes and the profiles that use it. It holds a note of theory and the procedure of one session. It depends on the kernel alone, as the [layers](../kernel/foundations/layers.md) require.

- [Bibliography](bibliography/_index.md): serves the role sensing where the environment is a literature
- [Mathematical mastery](mathematical-mastery/_index.md): serves the role capability where the competence is mathematical

> [!NOTE] Modules not yet written
> The sketched profiles call for analogous modules, such as the interviews of customers for the sensing of a founder. None is written.
