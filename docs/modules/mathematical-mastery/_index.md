# Mathematical mastery

Serves the role **training** under the regime `floor`. Used by the [research profile](../../profiles/research.md), and applicable to any profile whose competence rests on proofs or derivations.

- [Mastery](mastery.md): organizes training so that delegation does not replace the understanding of the agent
- [Learning session](learning-session.md): conducts one session of training without automated agents
