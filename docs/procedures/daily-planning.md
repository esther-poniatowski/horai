# Daily planning

> [!QUESTION] Goal: how are the objectives of a day fixed from the committed week, in 5 minutes?

1. **Calendar.** Read the themes, the windows and the committed blocks of the day.
2. **Main objective.** For the longest theme, apply the [selection rule](../kernel/processes/task-selection.md#^selection-rule) and mark the first task as the main objective.
3. **Other marks.** Mark further tasks, one per remaining theme, up to `daily_marks`.
4. **During a theme.** Record each interruption, idea or defect in the inbox, and return to the task. Serve only a request of the class `immediate`, and log the interruption.
5. **During a window.** Run the [request triage](request-triage.md) on the requests received, and do the tasks that release a wait. Return the unused part of the window to the next theme.
6. **Close.** Log the time spent on each parent, with the time spent verifying delegated output stated apart.
